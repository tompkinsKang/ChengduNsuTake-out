项目简介
本项目是一款面向学校食堂商家的送餐软件，分为 客户端 和 商家端 两个部分：
商家端：支持员工管理、商品管理（增删改查）、订单查看与数据分析等功能。
客户端：实现了在线点餐、下单、订单催促等操作，提升了用户就餐体验与商家运营效率。

技术选型
本项目采用了后端主流的技术栈，核心框架为 Spring Boot，提供了快速开发与自动配置能力。
数据库方面使用 MySQL 存储系统核心数据，结合 Redis 进行高频数据缓存，提升系统响应速度。
用户认证采用 JWT（JSON Web Token）方案，实现无状态的身份验证，同时通过 ThreadLocal 和自定义拦截器完成 token 校验逻辑。
在文件存储方面，接入了阿里云 OSS 服务，实现商品图片等静态资源的上传与分发。
实时通知功能基于 WebSocket 协议，实现订单状态变更、催单提醒等双向通信机制。
数据导出方面，项目集成了 Apache POI 库，支持将订单等数据导出为 Excel 报表，方便商家分析与归档。
